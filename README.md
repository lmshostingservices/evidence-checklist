# Evidence Checklist for Moodle (mod_evidencechecklist)

Public issue tracker for **Evidence Checklist**, the Moodle activity for practical observations by LMS Labs (LMS Hosting Services).

- Documentation: https://lms-labs.com
- Supported Moodle versions: 4.4 to 5.3

## Report a bug or request a feature

Open an issue: https://github.com/lmshostingservices/evidence-checklist/issues/new/choose

Please include your Moodle version, the plugin version (Site administration > Plugins > Plugins overview), your theme, the browser and device, and the steps to reproduce. Screenshots help.

**Do not post student names, photos, evidence files or other personal information in an issue.** This tracker is public.

## Security issues

Please do not report security problems here. Contact us privately through https://lms-labs.com instead.
